# البنية التقنية لمشروع VeriPitch (Proposed Architecture)

## 1. المنهجية الأساسية: RAG (Retrieval-Augmented Generation)
لتحقيق هدف "الصدق بنسبة 100%" ومنع "الهلوسة"، سنعتمد تقنية RAG. بدلاً من الاعتماد على المعرفة العامة للذكاء الاصطناعي، سنقوم بـ:
1. **استرجاع (Retrieve):** جلب مهارات المستقل وخبراته الحقيقية من قاعدة بياناته.
2. **تزويد (Augment):** إعطاء هذه البيانات المحددة للنموذج (LLM) كـ "سياق" (Context) وحيد مسموح به.
3. **توليد (Generate):** صياغة العرض بناءً على هذا السياق فقط.

## 2. المكونات التقنية (Tech Stack)

### الخلفية (Backend)
- **اللغة:** Python (لقوتها في مجال الذكاء الاصطناعي).
- **الإطار البرمجي:** FastAPI (لسرعته وسهولة بناء APIs).
- **الذكاء الاصطناعي:** LangChain أو LlamaIndex لإدارة تدفق بيانات RAG.
- **النماذج (LLMs):** OpenAI GPT-4o أو Anthropic Claude 3.5 Sonnet (لقدرتهما العالية على الالتزام بالسياق).

### قاعدة البيانات (Databases)
- **قاعدة بيانات علائقية (PostgreSQL):** لتخزين بيانات المستخدمين، الملفات الشخصية، وتاريخ العروض.
- **قاعدة بيانات متجهة (Vector Database - e.g., Pinecone or ChromaDB):** لتخزين "تضمينات" (Embeddings) مهارات وخبرات المستقل لتسهيل عملية البحث والمطابقة السريعة مع وصف الوظائف.

### الواجهة الأمامية (Frontend)
- **الإطار البرمجي:** React.js مع Tailwind CSS (لواجهة سريعة واستجابة عالية).
- **إدارة الحالة:** TanStack Query (React Query).

## 3. تدفق البيانات (Data Flow)
1. **المدخلات:** يرفع المستخدم (وصف الوظيفة) و (ملفه الشخصي - إذا لم يكن مسجلاً).
2. **التحليل:** يقوم النظام بتحويل مهارات المستخدم ووصف الوظيفة إلى Vector Embeddings.
3. **المطابقة:** يتم البحث عن أكثر المهارات والخبرات صلة بمتطلبات الوظيفة.
4. **بناء الأمر (Prompt Engineering):** يتم صياغة أمر للذكاء الاصطناعي يحتوي على:
   - مهارات المستقل ذات الصلة.
   - تفاصيل الوظيفة.
   - تعليمات صارمة بعدم إضافة أي معلومة غير موجودة في المهارات.
5. **المخرجات:** يظهر العرض النهائي للمستقل مع قائمة بالفجوات المعرفية التي يجب عليه تعلمها.

## 4. ضمان الجودة ومنع الهلوسة
- **Validation Layer:** طبقة برمجية بعد التوليد تقارن الكلمات المفتاحية في العرض مع الكلمات المفتاحية في ملف المستقل للتأكد من عدم وجود ادعاءات كاذبة.
