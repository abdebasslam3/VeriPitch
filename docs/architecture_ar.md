# البنية التقنية لمشروع VeriPitch (Proposed Architecture)

## 1. المنهجية الأساسية: RAG (Retrieval-Augmented Generation)
لتحقيق هدف "الصدق بنسبة 100%" ومنع "الهلوسة"، نعتمد تقنية RAG لضمان أن كل كلمة في العرض مستمدة من حقيقة موجودة في ملف المستقل.

## 2. المكونات التقنية المحدثة (Refined Tech Stack)
- **Backend:** Python / FastAPI.
- **Data Logic:** محرك مطابقة يعتمد على Regex (حالياً) و Vector Embeddings (مستقبلاً).
- **Security:** إضافة طبقة معالجة استثناءات ونظام Logging مركزي لمراقبة الأداء.
- **Testing:** منظومة اختبارات برمجية (Unit Tests) لضمان استقرار المحرك الأساسي.

## 3. خارطة الطريق التقنية (Technical Roadmap)
1. **الآن:** محرك مطابقة يعتمد على الكلمات المفتاحية (Keyword-based Matcher).
2. **المستقبل القريب:** الانتقال إلى Semantic Search باستخدام Sentence-Transformers.
3. **التكامل:** ربط النظام بواجهات برمجة التطبيقات (APIs) لمنصات العمل الحر (Upwork/Freelancer) لجلب الوظائف تلقائياً.

## 4. استراتيجية منع الأخطاء
- **Input Validation:** فحص كافة المدخلات باستخدامRegex وتنظيفها.
- **Graceful Failure:** في حال فشل النظام في تحليل مهارة معينة، يتم تسجيل الخطأ وتنبيه المستخدم دون توقف النظام.
- **Automated Testing:** تشغيل اختبارات شاملة عند كل تحديث برمجى لضمان عدم حدوث تراجعات (Regressions).
