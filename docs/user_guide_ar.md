# دليل تشغيل منصة VeriPitch للاستخدام التجاري

هذا الدليل يشرح لك خطوة بخطوة كيف تحول الكود الحالي إلى منصة حية جاهزة لاستقبال العملاء والبدء في تحقيق الأرباح.

## الخطوة الأولى: إعداد البيئة (Environment Variables)
يجب عليك إعداد مفاتيح الربط لضمان تواصل المنصة مع Whop ومعالجة البيانات.
1. قم بإنشاء ملف باسم `.env` في المجلد الرئيسي للمشروع.
2. أضف القيم التالية (استخدم القيم التي حصلت عليها من لوحة تحكم Whop):
```env
WHOP_API_KEY=sk_live_... (مفتاح الـ API الخاص بك)
NEXT_PUBLIC_WHOP_APP_ID=app_... (معرف التطبيق الخاص بك)
NEXT_PUBLIC_API_URL=/api/v1 (اتركها كما هي للنشر على Netlify)
```

## الخطوة الثانية: ضبط إعدادات Whop
للسماح للعملاء بتسجيل الدخول:
1. اذهب إلى [Whop Developer Dashboard](https://whop.com/dash/developer/).
2. في إعدادات تطبيقك، اذهب إلى قسم **OAuth**.
3. أضف رابط إعادة التوجيه الخاص بـ Netlify بعد النشر (مثال: `https://veripitch.netlify.app/api/auth/whop`).
4. تأكد من إنشاء "منتجات" (Products) في Whop ليتمكن العملاء من شرائها.

## الخطوة الثالثة: النشر على Netlify
هذه هي الخطوة التي تجعل موقعك متاحاً للعالم:
1. قم برفع الكود إلى مستودع خاص على **GitHub**.
2. اذهب إلى [Netlify](https://www.netlify.com/) واضغط على **Add new site** ثم **Import from git**.
3. اختر مستودع VeriPitch.
4. **إعدادات البناء (ستكون ملقنة تلقائياً بفضل ملف netlify.toml):**
   - Build Command: `cd frontend && npm run build`
   - Publish directory: `frontend/.next`
5. اذهب إلى **Site Configuration > Environment variables** في Netlify وأضف نفس المتغيرات الموجودة في ملف `.env`.

## الخطوة الرابعة: تجربة تدفق العميل (Customer Flow)
قبل إرسال الرابط للعملاء، تأكد من تجربة المسار التالي:
1. يدخل العميل على الصفحة الرئيسية للمنصة.
2. يضغط على "سجل دخولك عبر Whop".
3. يتم توجيهه إلى Whop للموافقة على الصلاحيات.
4. يعود العميل إلى لوحة التحكم (Dashboard) ويبدأ بمطابقة مهاراته وصياغة عروضه.

## الخطوة الخامسة: الصيانة والدعم
- **تحديث المهارات:** يمكنك إضافة مهارات جديدة في ملف `data/skills.json` وسيتعرف عليها النظام تلقائياً.
- **مراقبة الأداء:** يمكنك رؤية سجلات العمل (Logs) من خلال لوحة تحكم Netlify Functions.
