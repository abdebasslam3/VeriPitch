# VeriPitch

يهدف **VeriPitch** إلى حل أكبر مشكلتين تواجه المستقلين (Freelancers) عند التقديم على الوظائف: "الوقت المستغرق في كتابة عروض احترافية" و"مظهر عدم الاحترافية أو الكذب الناتج عن هلوسة الذكاء الاصطناعي". المنصة تضمن صياغة عروض عمل (Proposals) مقنعة، صادقة 100%، ومبنية فقط على مهارات المستقل الحقيقية، مع توفير بيئة تعليمية لسد فجواته المعرفية.

---

## 🚀 كيفية البدء (Quick Start)

### 1. إعداد المتغيرات البيئية
قم بإنشاء ملف باسم `.env` في المجلد الرئيسي وأضف فيه بيانات Whop الخاصة بك (تم إعدادها لك بالفعل):
```env
WHOP_API_KEY=your_api_key_here
NEXT_PUBLIC_WHOP_APP_ID=your_app_id_here
```

### 2. تشغيل الخلفية (Backend - FastAPI)
تأكد من تثبيت Python 3.10+ ثم نفذ الأوامر التالية:
```bash
# تثبيت المكتبات اللازمة
pip install -r requirements.txt

# تشغيل الخادم
python3 main.py
```
سيكون الخادم متاحاً على: `http://localhost:8000`

### 3. تشغيل الواجهة الأمامية (Frontend - Next.js)
اذهب إلى مجلد frontend وقم بتثبيت المكتبات وتشغيل التطبيق:
```bash
cd frontend
npm install
npm run dev
```
ستكون الواجهة متاحة على: `http://localhost:3000`

## 📁 هيكل المشروع
- `core/`: يحتوي على منطق مطابقة المهارات وعميل Whop.
- `data/`: يحتوي على قاعدة بيانات المهارات التقنية.
- `docs/`: يحتوي على التوثيق الفني باللغة العربية ودليل إعداد Whop.
- `frontend/`: تطبيق Next.js المتكامل مع Whop OAuth.
- `tests/`: اختبارات برمجية لضمان جودة الكود.

## 🛠 المميزات الحالية
- **محرك مطابقة ذكي:** يدعم المهارات المركبة والرموز التقنية (C++, .NET).
- **تكامل Whop:** نظام مصادقة وتحقق من العضويات جاهز للاستخدام.
- **منع الهلوسة:** صياغة عروض بناءً على البيانات الحقيقية فقط (RAG Ready).

للمزيد من التفاصيل حول الربط مع Whop، راجع الملف: `docs/whop_setup_ar.md`
